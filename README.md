Forecasts how many people will be watching Grand Theft Auto VI live on Twitch in each hour of its release day, from the first hour's viewer count. It fits the launch-day shape of past big rolling-midnight console launches — the log ratio of each hour's viewers to the hour-1 print, adjusted for how big that first hour was — and reports five quantiles an hour, so the forecast says how sure it is as well as what it expects.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
